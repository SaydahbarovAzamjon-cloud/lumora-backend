# Lumora Backend

AI-powered Personal Stylist Backend built with NestJS, GraphQL, MongoDB, Redis, and BullMQ.

## 🚀 Tech Stack

- NestJS
- GraphQL
- MongoDB
- Redis
- BullMQ
- Docker
- TypeScript

## 📦 Features

- Authentication & Authorization
- User Management
- AI Analysis Integration
- Outfit Recommendation
- Wardrobe Management
- Notifications
- Background Jobs
- File Uploads

## 📂 Project Structure

This project follows a monorepo architecture.

```
apps/
 ├── api
 └── batch
```

## 🛠️ Getting Started

```bash
npm install
npm run start:dev
```
